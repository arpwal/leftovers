Where did my disk space go?

Leftovers splits your disk into three parts: macOS, your apps, and your files. Then it finds junk files that are safe to delete. On one Mac, Xcode had 93 GB of old files.

It never deletes your code or your documents.

If your disk gets almost full, you get one alert a day.

Big clean ups

On one Mac: 40 broken iPhone test devices, using 7 GB. Leftovers only looks for these when you ask.

The project copies your agents forgot.

Agents make a new copy of your code for each task. They don't delete it when they're done. Leftovers finds the copies whose work is already saved, and removes them.

When the Spotlight helper gets stuck.

Your Mac has a helper that tells Spotlight when a file changes. If you change lots of files every day, this helper can get stuck. It eats memory and makes your whole Mac slow. Leftovers watches it. When it gets stuck, Leftovers restarts it.

Its real name is fseventsd.

20 GB after 31 days

It made one Mac very slow. One restart fixed it in 30 seconds.

50 MB is the limit

If it uses more, Leftovers steps in. You can change the limit.

1 restart per 30 min

If it keeps getting stuck, Leftovers waits longer and asks you what to do.

  • You see a ⚠︎ at the top of your screen, and an alert with a Restart button
  • Say yes once, and Leftovers fixes it on its own from then on
  • If you don't say yes, it asks for your password each time you click Restart

Every task that runs on its own.

Agents also set up tasks that run by themselves, like one every 20 minutes. Leftovers shows each one. It shows when it runs next, and if it works.

  • Pause it, run it now, or throw it away
  • See which agent made it, and why
  • Broken tasks are easy to spot

Agents can use it too.

You can also run Leftovers by typing commands. That way, a coding agent can check memory and clean up after itself.

# add the command once
ln -s /Applications/Leftovers.app/Contents/MacOS/Leftovers ~/.local/bin/leftovers

leftovers --report    # a short summary
leftovers --json      # the same, for agents
leftovers --clean     # quit the leaks
leftovers --jobs      # tasks that run on their own
leftovers --worktrees # old project copies
leftovers --fseventsd # the Spotlight helper

When an agent sets up a task, it can leave a short note in ~/Library/Application Support/Leftovers/jobs/. Leftovers shows the note next to the task.
